# Design Tokens
This page is a documentation of the design tokens used in the design system.
Every token found here is represented by a CSS variable prefixed with `--wcs`.

E.g: `primitive.color.parme.500` corresponds to the CSS variable `var(--wcs-primitive-color-parme-500)`.

> If you want to integrate these tokens into your project, please refer to the **[Theming documentation](?path=/docs/documentation-theming--documentation)**.

## Primitives
Primitives tokens are tokens mapped to raw CSS values. They are used to define the base of the design system.

Semantic tokens are tokens mapped to primitives values. They represent a choice of design for a specific context.
