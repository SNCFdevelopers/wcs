# Migrate from v6 to v7

WCS v7 contains breaking changes only in the following packages:
- wcs-core
- wcs-angular
- wcs-react

## wcs-core

### CSS Variables

During Design Tokens migration, we have **reviewed and updated certain CSS variables names on several components**. If you have used **any of the following CSS variables below**, you need to **update them** in your project or use the new ones.

#### wcs-button

- `--wcs-button-height` has been **deleted**. Use these one instead
    - use instead `--wcs-button-height-s`
    - use instead `--wcs-button-height-m`
    - use instead `--wcs-button-height-l`

#### wcs-input

- `--wcs-input-icon-color` has been **deleted**. Use these one instead
    - `--wcs-input-icon-color-default`: default icon color
    - `--wcs-input-icon-color-focus`: icon color on focus
    - `--wcs-input-icon-color-disabled`: icon color when disabled

#### wcs-textarea

- `--wcs-textarea-icon-color` has been **deleted**. Use these one instead
    - `--wcs-textarea-icon-color-default`: default icon color
    - `--wcs-textarea-icon-color-focus`: icon color on focus
    - `--wcs-textarea-icon-color-disabled`: icon color when disabled

#### wcs-select

- `--wcs-select-icon-color` has been **deleted**. Use these one instead
    - `--wcs-select-icon-color-default`: default icon color
    - `--wcs-select-icon-color-focus`: icon color on focus
    - `--wcs-select-icon-color-disabled`: icon color when disabled
- `--wcs-select-border-color` has been **deleted**. Use these one instead
    - `--wcs-select-control-border-color-default`: default border color
    - `--wcs-select-control-border-color-focus`: border color on focus
    - `--wcs-select-control-border-color-disabled`: border color when disabled
- `--wcs-select-outline-color` has been **deleted**. You have to use `--wcs-select-control-border-color-focus` instead.
- `--wcs-select-option-height` has been **deleted** from `wcs-select`. You have to use `--wcs-select-option-height` from `wcs-select-option` instead.
- `--wcs-select-border-width` has been **deleted** from `wcs-select`. Use these one instead
    - `--wcs-select-overlay-border-width`: border width of the overlay which contains the options
    - `--wcs-select-control-border-width`: default border width
    - `--wcs-select-control-border-width-active`: border width when select is opened
    - `--wcs-select-control-border-width-focus`: border width when select is focused
- `--wcs-select-border-radius` has been **deleted**. Use these one instead
    - `--wcs-select-control-border-radius`: default border radius
    - `--wcs-select-overlay-border-radius`: border radius of the overlay which contains the options

#### wcs-native-select

- `--wcs-select-native-outline-color` has been **deleted**. Use these one instead
    - `--wcs-select-native-border-color-default`: default border color
    - `--wcs-select-native-border-color-focus`: border color on focus
    - `--wcs-select-native-border-color-disabled`: border color when disabled

#### wcs-switch

- `--wcs-switch-bullet-color-initial` and `--wcs-switch-bullet-color-final` has been deleted. Use instead : 
    - `--wcs-switch-dot-color-initial`: for dot color inside switch when switch is not selected
    - `--wcs-switch-dot-color-final`: for dot color inside switch when switch is selected
- `--wcs-switch-text-color` has been deleted. Use instead : 
    - `--wcs-switch-text-color-default`: text color default
    - `--wcs-switch-text-color-selected`: text color when switch is selected
    - `--wcs-switch-text-color-hover`: text color when switch is hovered
    - `--wcs-switch-text-color-disabled`: text color when switch is disabled

#### wcs-badge

- Rename `--wcs-badge-ligther-percentage` to `--wcs-badge-lighter-percentage` (typo)

#### wcs-header

With design tokens migration, the `wcs-header` **is no longer dark**. As you can put `wcs-button` inside the `wcs-header`, you have to verify the button is still visible. 

Indeed, on storybook, we applied the `.wcs-light` class to the button to make it visible. As the `wcs-header` is no longer dark, you have to remove this class from the button to keep it visible if you have used it.

Before

```html
        <wcs-header>
            <img
                slot="logo"
                alt="SNCF"
                src="data:image/svg+xml;base64,PD94...."
            />
            <h1 slot="title">Votre superbe application</h1>
            <div slot="actions">
                <wcs-button class="wcs-light" mode="clear"> <!--The class wcs-light was here-->
                    <span>Connexion</span>
                    <wcs-mat-icon icon="person_outline"></wcs-mat-icon>
                </wcs-button>
            </div>
        </wcs-header>
```

After

```html
        <wcs-header>
            <img
                slot="logo"
                alt="SNCF"
                src="data:image/svg+xml;base64,PD94...."
            />
            <h1 slot="title">Votre superbe application</h1>
            <div slot="actions">
                <wcs-button mode="clear"> <!--The class is no longer applied-->
                    <span>Connexion</span>
                    <wcs-mat-icon icon="person_outline"></wcs-mat-icon>
                </wcs-button>
            </div>
        </wcs-header>
```
