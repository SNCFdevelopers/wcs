# Wcs Core

This documentation covers the features provided by the `wcs-core` package. The main goal of this package is to provide web components for direct use. Whether in SSR, without a framework, or by integrating them yourself into your favorite frontend library/framework. This package also provides all assets (styles, icons, etc.).

## Components

Several distribution formats are available to use WCS components, each with its own use cases and features. Each format is described in its own documentation, for more details, please refer to the corresponding page where you will find typical use cases and integration examples.

The `wcs-core` package is structured as follows:
- `dist`: Distributable and lazy-loaded components. Follow the [dist documentation](./?path=/docs/documentation-getting-started-core-dist--documentation) for more details.
- `bundle`: Bundled components in an optimized single file with runtime and no lazy loading. Follow the [bundle documentation](./?path=/docs/documentation-getting-started-core-bundle--documentation) for more details.
- `composite-elements`: All component are exported within a single file, a component and its children will be automatically defined when the component's module is imported. Follow the [composite-elements documentation](./?path=/docs/documentation-getting-started-core-composite-elements--documentation) for more details.

## Assets

The `wcs-core` package includes all the necessary assets for WCS components, such as styles and so on.

If you are using scss preprocessor or a bundler, you can directly import the wcs styles from the node_modules by referencing the path to the package.

```scss
/* styles.scss */
@import 'wcs-core/dist/wcs/wcs.css';

```

If it's not the case, you can directly link the css file in your html, served from a CDN like jsdelivr or you web server.

```html
<!DOCTYPE html>
<html lang="fr">
<head>
    ...
    <link rel="stylesheet" href="wcs-core/dist/wcs/wcs.css">
    <link rel="stylesheet" href="wcs-core/design-tokens/dist/sncf-holding.css">
</head>

```
